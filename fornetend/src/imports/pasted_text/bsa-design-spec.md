Design a complete responsive website for a student gaming platform called **“Béjaïa Student Arcade”**.

The website is a collaborative project created by students in Béjaïa. It should feel like a **modern digital arcade**: energetic, playful, competitive, nostalgic, and highly interactive — inspired by classic arcade machines and pixel games, but with a clean modern UI.

## 1. Visual Identity

Create a strong arcade-inspired visual identity.

Style:

* Retro arcade + modern web design
* Dark-first interface
* Pixel-art inspired details
* Neon accents
* Subtle CRT/scanline effects
* Glowing borders and buttons
* Pixel-inspired decorative elements
* Smooth modern animations
* Fun but not childish
* Competitive gaming atmosphere

The design should feel like entering a digital arcade.

Avoid:

* Generic esports websites
* Overly futuristic sci-fi interfaces
* Excessive gradients
* Cluttered layouts
* Corporate SaaS styling
* Too many colors

Use a dark background with a carefully controlled neon palette.

Suggested colors:

* Background: #080812
* Secondary background: #11111F
* Card background: #171727
* Primary accent: electric purple
* Secondary accent: neon cyan
* Highlight: arcade pink
* Success/high score: neon green
* Text: #F5F3FF
* Muted text: #9B97B5

Use pixel/arcade typography for headings where appropriate, combined with a highly readable modern font for body text.

## 10. INTERACTIONS

Design interactions that make the website feel like an arcade.

Examples:

* Buttons glow when hovered
* Game cards slightly lift and glow
* Pixel particles appear around important interactions
* Leaderboard rows highlight on hover
* Achievement badges have subtle animations
* Page transitions feel smooth
* Game-over modal has an arcade-style entrance animation
* Score updates have a satisfying visual effect

Keep animations subtle enough that the interface remains usable.

---

## 11. IMPORTANT DESIGN DIRECTION

The final result should feel like:

“Walking into a modern arcade built specifically for Béjaïa students.”

It should combine:

* Retro arcade nostalgia
* Student community
* Competition
* Gaming
* Modern web design

The website should look polished enough for a real public launch, not like a basic student assignment.

Prioritize:

1. Strong visual identity
2. Excellent game discovery
3. Clear navigation
4. Competitive leaderboard experience
5. Responsive design
6. Reusable components
7. Consistent spacing and typography
8. Accessibility and readability

Create the complete design system and all major screens so that the frontend developers can directly use the Figma design as their implementation reference.
